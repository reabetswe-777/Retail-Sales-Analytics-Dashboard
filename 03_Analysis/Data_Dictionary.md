1. Business Problem Statement
The main objective of this project is to analyse retail sales performance, customer purchasing patterns, and product profitability using the Superstore dataset. This analysis aims to uncover growth patterns, highlight key sales regions, and identify low-margin product categories to assist management in making decisions which are data-driven.

2. Data Dictionary
Column Name	Data Type	Description
Order ID	Text	Unique identifier for each order
Order Date	Date	Date when order was placed
Ship Date	Date	Date when order was shipped
Ship Mode	Text	Mode of shipment
Customer ID	Text	Unique identifier for customers
Customer Name	Text	Name of customer
Segment	Text	Target market segment of customer
Country	Text	Country where order was placed or delivered
City	Text	Specific city location of the customer delivery address
State	Text	State or administrative territory where transaction occurred
Region	Text	Broader geographic sales territory assigned to the location
Category	Text	Broad product category
Sub-Category	Text	Specific product sub-category
Sales	Number	Total revenue generated
Quantity	Integer	Number of units purchased
Discount	Decimal	Percentage discount applied
Profit	Number	Net profit or loss
