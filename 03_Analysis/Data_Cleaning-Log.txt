2. LIST OF CALCULATED FIELDS ADDED
- Year: =YEAR([@[Order Date]]) -> Extracts 4-digit year for annual trends
- Month: =TEXT([@]Order Date]],"mmm") -> Extracts month name for seasonal analysis
- Year-Month: =TEXT([@[Order Date]]),"yyyy-mmm")
- Profit Margin (%): =([@Profit]/[@Sales])*100 -> Measures profitability per transaction
- Average Order Value (AOV): Total Sales/Total Unigue Orders -> Key summary metric
